# A Little Question ❤️

A romantic, responsive proposal website made with HTML, CSS, and JavaScript.

## Features
- Animated envelope that opens when the heart seal is clicked.
- “Will you marry me?” letter.
- YES and playful NO buttons (the NO button moves away when approached).
- A celebration card appears after clicking YES.
- Floating hearts and sparkles.
- Responsive layout for phones and desktops.

## Run locally
1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`, or open it with VS Code and use the Live Server extension.

No build tools or installation are required. An internet connection is used only to load the decorative Google Fonts; the website itself works without them using fallback fonts.

## Publish with GitHub Pages
1. Create a GitHub repository and upload all three files: `index.html`, `style.css`, and `script.js`.
2. Open the repository's **Settings**.
3. Select **Pages** from the sidebar.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then click **Save**.
6. Wait a minute or two. GitHub will show your website URL in the Pages section.

You can personalize the message in `index.html` by editing the text inside the `.message` paragraph.
